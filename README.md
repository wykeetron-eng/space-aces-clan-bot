# Space Aces Clan Bot

Discord bot that reads Space Aces clan data and updates
Discord embeds automatically.

## Features

- Clan statistics
- Credits
- Uritaium
- PvP/PvE kills
- Clan ranking
- Clan level
- Clan upgrades
- Recent activity

The bot polls the Space Aces API every 2 minutes.
